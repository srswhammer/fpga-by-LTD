本包保持 `digitcnn_v1_int8` 数值版本。目录中的 candidate 文档和 reproduction 是推导历史，不是另一个要交付的模型；运行时以 release/config.json 为准。

不要根据“参数只有 6852 字节”断言整个系统已满足 7Z015 资源预算。摄像头、显示、DMA、缓存、并行度和时钟都影响实现结果。

读取导出参数再调用同一推理实现，可以证明序列化一致性；不能单独证明实现公式正确。本次打包另外加入了 Python 标量整数逐层复算，用独立循环核对固定十张及边界输入，见 packaging_checks.json。

固定十张是选择过的正确样本，只用于确定性联调。未来需要另加随机、边界、错误分类和实拍输入进行板上验证。测试集结果用于报告；后续调参应使用训练/验证集，避免不断根据测试集调整。
