# 手写数字 CNN 候选结构 v1

状态：结构已验证并完成 float32 基线训练；仍供 A 评估，不是最终硬件接口。

输入为 MNIST 灰度图片，经 ToTensor 转为 float32、范围 0 到 1；布局 NCHW，单图 [1,28,28]。此版本不额外进行均值方差标准化。

| 层 | 配置 | 单图输出形状 | 参数量 | 单图 MAC 数 |
|---|---|---|---:|---:|
| 输入 | 灰度 | 1×28×28 | 0 | 0 |
| Conv2d | 1→4 通道，3×3，stride=1，padding=0，有偏置 | 4×26×26 | 40 | 24336 |
| ReLU | 负数置零 | 4×26×26 | 0 | 0 |
| MaxPool2d | 2×2，stride=2 | 4×13×13 | 0 | 0 |
| Flatten | 通道→行→列，列变化最快 | 676 | 0 | 0 |
| Linear | 676→10，有偏置 | 10 | 6770 | 6760 |
| 合计 | | | 6810 | 31096 |

MAC 指一次乘加；这里仅统计卷积与全连接的权重乘加，不包含偏置加法、ReLU、池化比较、搬运、控制开销，不能直接换算成 FPGA 时钟周期。

float32 参数原始数据量为 6810×4=27240 字节，不含文件元数据。实际硬件存储还涉及中间特征、缓存和量化参数，不能仅依据权重大小判断资源是否充足。

输出为对应数字 0～9 的十个原始分数，不是概率。分类可取最大分数的索引；未训练时的预测没有识别价值。

PyTorch Conv2d 采用互相关计算（不翻转卷积核）。卷积权重布局为 [输出通道,输入通道,核行,核列]，全连接权重为 [输出,输入]。后续硬件映射需双方明确确认。

待与 A 确认：是否采用本结构、RTL/HLS 路线、支持的算子、存储与复用策略，以及所有整数数值规则。本阶段没有导出可直接用于整数硬件的权重。
